# GPS Sentinela

Aplicativo Android experimental para identificação aproximada de vias. Requer internet e permissão de localização. Uso em primeiro plano. Não oficial; confirme a localização antes de transmitir.

## Compilação
GitHub Actions: Java 17, Gradle 8.9 e SDK 35. Baixe GPS-Sentinela-APK-teste na execução concluída e extraia app-debug.apk.
